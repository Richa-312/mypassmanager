# 🔐 MyPassManager

**MyPassManager** is a secure, modern password manager Android app built with **Kotlin**, **Jetpack Compose**, and **Room**. It features **biometric authentication**, **AES encryption**, and a clean Compose-based UI to help users store and manage their credentials securely.

---

## ✨ Features

- 🧠 Built with Jetpack Compose & MVVM architecture
- 🔒 Biometric Authentication (Fingerprint/Face Unlock)
- 🗄️ Room Database for local secure storage
- 🛡️ AES Encryption using Android Security Crypto
- ➕ Add / 📝 Edit / 🗑️ Delete password entries
- 🎨 Clean and responsive UI based on Figma design
- 📂 Completely offline, no internet permission required
